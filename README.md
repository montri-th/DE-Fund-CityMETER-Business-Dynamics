# CityMETER: Business Dynamics — DE Fund proposal explainer

Interactive single-page explainer for the funding consideration of **CityMETER: Business Dynamics**.

- Requested funding: **THB 9,490,000**
- Project term: **365 days**
- Delivery plan: **6 evidence-linked instalments**
- Design system: **Landometer Design System v0.8.8**
- Release status: **provisional / public / noindex**

Open [`index.html`](./index.html) directly in a modern browser. The file is standalone: the project-supplied logo asset, Thai/Latin font subsets, styles, interactions, print rules, and machine-readable Build Card/QA records are embedded.

The page distinguishes the proposed co-implementing role of depa from a signed commitment. It also keeps source rights, coverage, comparability, staffing, supplier pricing, and working-capital items visible as gates that must be closed before submission or contract execution.

## Verification

The release was checked at 320, 390, 768, and 1440 px widths, in light and dark themes, with JavaScript disabled, with reduced motion, by keyboard, and in print mode. Static validation found no HTML, control-inventory, embedded-asset, arithmetic, fragment-target, or JavaScript syntax errors.

Machine validation remains marked `pending` because the generated Landometer v0.8.8 schema package and identity-authority approval record were not available in the supplied project sources. The page therefore must not be represented as a final verified or indexable release.
